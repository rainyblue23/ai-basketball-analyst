## 新增配置

API `JobCreate` 和 `VideoSource`：

| 参数 | 默认 | 用途/回退 |
| --- | --- | --- |
| `player_track_stitch` | false | 保留原临时ID；true启用受队别/切镜/唯一性约束的启发式补接。它不是跨镜头真实身份识别 |
| `legacy_detect.ball_min_side_px` | 4.0 | 原始画面像素，范围2～32；null恢复`.012×min(width,960)`旧门限 |

| `legacy_detect.rim_refinement` | true | 允许细化不适配的hoop区域；false恢复仅接纳原模型篮圈几何的行为 |
| `legacy_detect.rim_refinement_options` | 见下 | 每项可单独配置；拒绝上下界倒置/越界 |

## 实际结果

### 1. GPU整段回归

使用相同默认模型和未标定smoke口径：球员stride2、legacy standard、无人工出手回填、两个ROI关闭；Lillard开启OCR，Dairy关闭OCR。未渲染高光或叠框视频。

| 项目 | Lillard原基线 | Lillard本轮 | Dairy本轮 |
| --- | ---: | ---: | ---: |
| 实际解码帧 | 902 | 902 | 836 |
| 程序报告时长 | 34.835s（错误元数据） | 30.097s | 27.867s |
| 有效篮筐帧 | 0 | 191 | 835 |
| 模型实测球帧（不是准确率） | 93 | 123 | 223 |
| 运动块被算作实测帧 | 71 | 0 | 0 |
| 投篮事件 | 0 | **0** | **0** |
| 处理耗时 | 54.985s | 56.917s | 36.601s |
| 处理FPS | 16.404 | 15.848 | 22.841 |

两段真实素材抽看定位见各目录的contact_sheet图片，绿色框为细化篮圈，红色框为原模型粗区域；这是定位检查，不是人工完整框真值。篮筐可用率是内部观测指标，不能叫篮筐Recall。

**结论：部分篮筐定位阻断已修复，但自动投篮漏检尚未修复。** 两段仍0出手，没有通过降低判据凑次数。球的真实连续观测、远景/高弧线恢复、出手证据仍需步骤4、5继续处理。没有独立测试真值，不宣称整体识别准确率提升。

单次耗时包含模型建立、检测及相应OCR；测前做过GPU工作，部分CPU测试并发，未控制冷/热启动且未重复测量，不能从约2秒差异推断性能回退或加速效果。Dairy的无OCR时间不可直接与Lillard比较。
