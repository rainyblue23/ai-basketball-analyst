### 时间与归属的限制

这里没有手部关键点或动作模型。球心进入上半身扩展框只是**近身代理证据**，不是实际手球接触；离手时间仍是估计。`release_evidence.timestamp_estimated=true`、`timestamp_source=last_upper_body_proximity`，`interval_s`描述近身到分离的采样区间，不能理解成真实物理离手时刻的严格上下界。

原 `release_t` 保持数字以兼容回看/高光接口；`release_known=false`时它是候选回看时刻。不能只读取release_t就把它当作已经测准的出手时间。临时track ID也不是跨镜头真实球员身份。

## 新增配置与回退

在现有 `legacy_detect.shot_evidence` 对象下传递，不新增顶层任务接口。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| release_binding_mode | contact_sequence | legacy_nearest_feet可恢复旧绑定，仅用于对照 |

| release_lookback_s | 2 | 历史回看窗口，允许至4秒，缓存同步受限 |

| release_contact_max_gap_s | .25 | 近身观测最大间隔，最大.5秒 |
| release_departure_max_gap_s | .25 | 分离观测最大间隔，最大.5秒 |
| release_ambiguity_s | .1 | 两个候选归属时间过近时保持未知 |
| release_contact_x_pad_ratio | .25 | 上半身区域左右扩展，按人体框宽 |
| release_contact_top_ratio | -.2 | 区域上边缘，按人体框高相对框顶 |
| release_contact_bottom_ratio | .75 | 区域下边缘，不将脚底附近视为持球接触 |

  "release_binding_mode":"legacy_nearest_feet",
